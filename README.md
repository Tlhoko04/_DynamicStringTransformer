# DynamicStringTransformer

A C# console utility built on .NET 10 designed for configurable string transformations, pattern replacements, and rule-based text processing.

## Features
-**Multi-Step Text Processing::** Chain multiple text edits together (like trimming, replacing, and formatting) in one go without stopping.
-**Custom rules:** Set your own rules for how text should be cleaned up, capitalized, or swapped out.
- **Modern .NET 10 Runtime:** Built targeting .NET 10 for fast, lightweight console execution.

## Tech Stack
- **Language:** C#
- **Platform:** .NET 10.0
- **Project Type:** Console Application
